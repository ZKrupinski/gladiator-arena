GitHub 토큰은 무엇이며 어디서 받나요?

직접 정하는 암호가 아니라 GitHub가 발급하는 접근 키입니다. 토큰 이름만 알아보기 쉽게 정하고, 실제 토큰 문자열은 GitHub에서 복사합니다.

  1. GitHub 토큰 발급 페이지 열기 → GitHub 로그인
  2. 이름과 만료일 설정 → Resource owner: ZKrupinski
  3. Only select repositories → gladiator-arena만 선택
  4. Repository permissions → Contents → Read and write
  5. Generate token으로 발급한 문자열을 아래 칸에 붙여넣기

토큰은 채팅에 보내지 마세요. 토큰 없이 저장하려면 ‘GitHub 편집기에서 저장’을 이용한 뒤 이 페이지에서 ‘저장·배포 상태 다시 확인’을 누르세요.

입력한 인증 토큰은 이 페이지에서 저장·기록하지 않고 GitHub API 요청에만 사용합니다. GitHub 사이트에서 직접 저장하려면 위 ‘GitHub 편집기에서 저장’을 사용하세요.

GitHub 기준 파일이 모든 기기의 공통 기본값입니다. 수정값을 게시하지 않으면 다른 기기에 전달되지 않습니다.
