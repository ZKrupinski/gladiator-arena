# SPARTACUS v67 — Lv.50 선천 특성 성장 / Concordia 매칭·경기시간 개선

2026-10-25 / GitHub main

## 성장 규칙 (모든 루두스 검투사)
- 이전 Lv.20 상한을 **Lv.50**으로 확대. `careerLevel`/`grantCareerXp`/경험치 UI/상대 레벨 생성 모두 50레벨을 지원. 기존 Lv.20 캐릭터는 현재 레벨을 유지하며 다음 경험치부터 Lv.21 도달 가능.
- 노예시장의 **Lv.0** `vals`를 신규 영입 시 `birthStats`라는 별도 불변 필드로 보존. `aptitudes` 선천 재능도 보존. 이미 훈련으로 올린 `stats` 값에 수정을 가하지 않음.
- `ArenaProgression`으로 경험치 레벨 성장에 따른 선천적 전투 잠재력 자동 발현: `16 × ((Lv−1)/49)^1.34 × (0.65 + (aptitude−1)×1.05 + (birth−4)×0.088)` (계수 0.28~1.72 제한).
- Lv.1 발현 보정 0, 후반 레벨에서 빠르게 개성 확장. **근력**은 공격력, **민첩**은 이동·스태미나 회복, **체력**은 HP·방어력, **집중**은 패링·스킬 쿨다운에 영향. 기존 훈련 포인트와 합산하되 저장 데이터에는 복사하지 않아 중복 획득 없음.
- 기존 저장된 검투사 중 `birthStats`가 없는 경우 중립 초기값을 쓰되 보유 `aptitudes`는 그대로 반영; 저장된 `stats`는 절대 소급 변형하지 않음.
- 루두스 검투사 관리 화면에 현재 누적 선천 성장 보정과 Lv.50 예상 강점/약점 표시. 5개 일러스트 등급은 Lv.20 이후 최종 등급 그대로 유지하고 숫자 레벨은 Lv.50까지 증가.
- 1vs1 매칭 `ArenaBalance`와 `LudusRoster`도 Lv.50 전투능력 기반을 지원. 레벨 자체의 무차별적인 후반 공격/HP 가속은 옛 Lv.20 곡선에 제한해 과격한 난도 폭주 방지.

## 5vs5 협동전 매칭 / 플레이 타임
- 기존 상대 생성은 선택팀의 평균 체력/공격력과 함께 특정 클래스별 고정 높은 HP/방어력을 사용했고 **부상·피로·장비**를 충분히 고려하지 못함.
- `ArenaCoopMatch.build()`: 실제 출전하는 다섯 명의 `LudusBridge.combatStats`(장비/훈련 및 Lv.50 성장 포함), 캐릭터별 체력, 부상·피로에 비례해 상대 5명의 체력과 공격력 재생성. 출전 편성창 상대 썸네일과 실제 시합 상대의 동일성을 유지.
- `ArenaCoopCore`에서 5vs5만 체력 버퍼 ×1.5, 기본 피해계수 .52 → .42, 상대방 포함 양 진영에 동일한 체력/피해 규칙. 레벨/스탯/원본 크기/실전훈련/일반전투의 능력치는 변경하지 않음.
- 120초 경기 제한은 유지. **전술을 쓰면서 약 50~60초대** 시합으로 조정해 방어진형·양익 돌파·연계총공세를 여러 번 사용 가능.
