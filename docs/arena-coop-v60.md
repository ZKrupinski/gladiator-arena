# Concordia v60 — 5vs5 자율 전술 연계 고도화
날짜: 2026-10-25

## 전투 핵심
- 5vs5 일반 아레나 탭만 변경. 1vs1, 연속전, 실전훈련, 기존 보상·저장 구조를 변경하지 않음.
- **공격/반격**: 패링 성공 → 돌진 반격 → 추가타 링크, 강타 넉백 → 최대 3인 추격 협공.
- **유인**: 일부 후퇴 검투사는 체력 회복을 포기하고 상대를 유인한다. 적의 추격 AI는 목표를 일정 시간 고정한다.
- **매복**: 유인된 추격자를 인근 동료가 가로막아 강타, 경직시키고 연계 협공을 부른다. 매복은 무한 재귀되지 않는다.
- **구출**: 체력이 낮아진 아군이 공격당하면 근처 동료가 한시적으로 구출 돌진을 한다. 성공하면 위협 적에게 타격/넉백, 아군에게 짧은 피해 감소 버프.
- **빈틈·회피**: 일반 견제·돌진·후퇴·잠깐 안전거리 체력 회복 로직 유지. 스태거/포획/후퇴 중인 검투사는 구출 동작을 억지로 시작하지 않는다.
- **거리/시체**: 투영된 발 위치 기준 SOLID_GAP=102, 고속 돌진과 밀려나기에도 이동 중 매 프레임 충돌 확인. 사망 시 시체는 불투명하고 장애물로 계속 남는다.
- **연출**: 도주 유인/맹추격/구출/매복 표시, 돌진 잔상, 공격 이펙트, 순간 구출 보호막, 상태별 콜아웃과 타격음.
- **명령**: 집중 공격 6초, 보호 진형 7초, 연계 총공세 기능은 동일. 새 자율 전술은 이들과 병행하여 발생한다.

## 검증
- `tests/arena-coop-core.js`: 기존 100 시드 승패/일시정지/지휘/시간제한/보상 분리 검증 + 유인/추격/매복/구출 이벤트, 시체 비통과 테스트 통과.
- `tests/arena-coop-tactics.js`: 250개의 서로 다른 팀 전력·속도 조합과 시드. 평균 69.1초, 전멸 종료 170회, 시간 종료 80회, 아군 115승, 적군 135승. 발 충돌 0건, 좌표/체력 유한 범위, 동적 이벤트 발생 확인.
- 수치는 시뮬레이션 테스트 기준. 실제 브라우저 수동 플레이/모바일 실기기/Cloudflare 프로덕션 배포 성공을 뜻하지 않는다.
- 모든 이미지 자산, 스프라이트 편집툴, 훈련 모드 코드를 수정하지 않았다.
