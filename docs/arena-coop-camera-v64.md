# Concordia v64 — 5vs5 전황 중심 카메라

2026-10-25

## 문제
v63에서는 5vs5의 10명에게 적용된 일반 1대1용 카메라 충격이 패링·강타·구출 이벤트가 겹칠 때 잦고 과했습니다. 진동 자체는 전황을 보여주는 카메라 움직임이 아니었으며, 배경도 구도 변화가 거의 없었습니다.

## 변경
- 신규 `public/arena-coop-camera.js` (화면 렌더링 전용)
  - **전체 전장 (overview)**: 보통 3.15초 정도, 이벤트가 중요할 경우 1.85초 이후 전환 가능
  - **공방 클로즈업 (close)**: 약 1.78초; 초반 0.62초 동안 부드럽게 줌
  - **전체 전장 복귀 (return)**: 약 1.02초 동안 줌아웃 및 중앙 복귀
  - 그 뒤 전체 전장으로 다시 돌아가기를 반복
  - 패링·돌진반격·동료구출·매복·강타의 실제 타격 좌표를 우선 촬영, 없으면 서로 가까운 적대 검투사 두 명을 선택
  - 모바일은 최대 7.1% 확대 (넓게 퍼진 10명일 때 더 낮음), 데스크톱은 최대 10.5% 확대 (실제 극초기 전장에서는 일반적으로 약 8%)
  - 실시간 렌더링 카메라만 계산: 전투 판정·물리·HP·키프레임·장비 및 게임 저장값에 간섭하지 않음
  - 원본 1280×720 배경 경계를 벗어나지 않는 X/Y 센터 제한; 줌과 이동 모두 부드럽게 보간
- `public/arena-coop.js`: 배경·캐릭터·시체·전투 래스터 이펙트를 똑같은 카메라 월드 변환 아래에서 렌더링. 기존 전투 렌더링 우선순위(시체 포함 발-Y 정렬) 보존
- `public/arena-combat-feel.js`: 오직 **team=true**인 5vs5에서만 진동을 0.38 게임초 이상 간격으로 제한하고 크기를 낮춤. 화면 진동 샘플은 X ±4px, Y ±2.4px, 회전 ±0.0018 rad 내 제한하며 실제 5vs5 화면에서는 추가 축소
  - 일반 결투/실전훈련의 기존 강한 연출 설정은 건드리지 않음
  - 5vs5 전용 히트스톱은 짧은 `strike` 프리셋을 사용. 장시간 1대1식 카메라 컷/슬로우를 남발하지 않음
  - 모바일은 오토 프레이밍이 너무 좁아지지 않도록 월드 시야폭 최소 920px를 유지하고 중심 이동을 부드럽게 보간
- 접근성 '동작 줄이기'에서는 카메라를 기본 광각으로 되돌리고 화면 플래시를 제거함

## 검증
- `tests/arena-coop-camera.js`: 45초 카메라 주기, 휴대전화·데스크톱 확대 상한, X/Y 프레임 경계, 부드러운 프레임 변화, 일시정지, reduced motion 통과
- 95개 실제 5vs5 시뮬레이션 기반 카메라 연동 테스트: 평균 약 36.81 게임초, **진동/렌즈 경계·비연속 프레임 오류 0건**, 총 664개 클로즈업 / 708개 전체보기 상태 시작
- 기존 `tests/arena-coop-core.js` 100시드, `tests/arena-coop-tactics.js` 250시드 전투/시체 통과/생존자 간 충돌 테스트 통과
- 모바일 실기기 GUI 화면 검수와 Cloudflare Pages 배포 완료는 확인되지 않았으므로 별도 브라우저 테스트 권장
