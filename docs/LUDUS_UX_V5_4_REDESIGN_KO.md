# GLADIATOR — LUDUS UX v5.4 · 화면별 재기획안

> 상태: **기획안 / 검투사 관리 신규 레이아웃 구현 전 검토용**. 
> 2026-10-17 루두스 로비 원본 키비주얼 복구 후 작성. 승인된 로비/시장/훈련소/장비실 그림은 독단적으로 덮어쓰지 않는다.

## 0. 반드시 지키는 약속

1. **메인 로비가 공간적 중심.** 모든 서브페이지의 '루두스 로비로 돌아가기'는 **화면 좌측 하단 같은 자리**에 한 개만 배치한다. 모바일 화면도 같은 상대 위치를 유지한다.
2. **원본 키비주얼 훼손 금지.** 도미나, 교관, 배경 인물, 조각상, 제단, 프레임, 장식은 최종 확인된 형태를 보존한다. 배경에 그려져 움직일 수 없는 NPC는 투명화한 깨끗한 배경 파일을 준비한 뒤 별도 스프라이트 레이어로 출력한다. 무리한 불투명 가림판/그라디언트 덧칠 금지.
3. **그림으로 남은 가짜 버튼 금지.** 눌러도 기능이 없는 UI는 이미지 리소스에서 제거 또는 비활성 장식으로 다시 그린다. 실제 버튼은 클릭 영역, 명칭, 버튼 상태를 갖는다.
4. **공통 로마/루두스 디자인 토큰.** 검붉은 장막, 청동·금박 테두리, 따뜻한 석재, 명암이 뚜렷한 3D풍 그림, 가독성 높은 크림색 글자. 메뉴의 금박·액자 질감과 눌림/선택 상태를 통일한다.
5. **리소스와 코드 분리.** `background-clean`, `npc/<name>/*.webp`, `panels`, `icons`, `overlays` 폴더로 분리. 스프라이트 위치는 씬의 기준 좌표 및 발바닥 앵커로 제어한다.
6. **반응형 고정 기준 좌표.** 승인된 1672×941 가로 서브페이지를 기본 디자인 캔버스로 사용. 로비의 기존 1448×1086 아트는 원본 종횡비 유지(비틀어 늘리지 않음); 레터박스/여백과 클릭 좌표 조정. 스크롤을 강제하지 않고 화면에 맞춰 축소한다.
7. **실제 게임 데이터만 표시.** 금화, 보유인원, 장비, 경험치, 승패, 부상, 능력치는 저장된 CAREER 상태와 직접 연결한다. 컨셉 이미지의 예시 숫자/초상/구매 버튼을 고정 노출하지 않는다.

## 1. 화면 체계

```
LUDUS 메인 로비
 ├─ 검투사 관리 (신규 중심 운영 페이지)
 │   ├─ 검투사 선택 / 출전 지정
 │   ├─ 훈련소로 이동
 │   ├─ 장비실로 이동
 │   └─ 부상 회복 / 다음 출전
 ├─ 훈련소 (승인된 훈련소 키비주얼)
 ├─ 장비실 (승인된 장비실 키비주얼)
 ├─ 검투사시장 (승인된 시장 키비주얼)
 └─ 아레나 출전 → 출전 선수 선택 → 전투 → 결과 → 로비
```

각 서브페이지에서 좌측 하단 **❮ 루두스 로비** 버튼 하나만 제공. 내부 화면 간 이동은 전용 행동 버튼으로 한다. 경기 도중 전투 HUD의 뒤로 가기와 결과창은 전투 진행 규칙을 우선한다.

## 2. 로비 (복구 우선)

- **키 비주얼:** 원래 승인된 도미나와 서브 NPC, 콜로세움 풍경과 밝은 로마 광장 유지. 기존 구도의 큰 변형 금지.
- **주 동선:** 훈련소 / 검투사 관리 / 장비실 / 검투사시장 / 아레나 출전. 유료 기능이나 로직 없는 교관·시설 강화·특훈·훈련 가속 같은 메뉴는 실제 구현 전까지 보이지 않게.
- **보조 정보:** 실금화·명예·소속 검투사 수와 선택 검투사 대표 초상(오로지 실데이터). NPC는 독립 스프라이트로 눈 깜빡임, 호흡, 손 동작, 시선/대사 변화.
- **검수:** 도미나 이미지 손상/중복 없음; 원본 상단 장식·우측 교관 위치 보존; 좌측 메뉴 클릭/화면 전환 이상 없음.

## 3. 검투사 관리 (신규 전용 디자인 — 이번 재기획 핵심)

단순 카드 나열/기존 HTML 표가 아닌 **로마식 검투사 명부와 관리실**. 승인된 시장과 장비실의 3D 게임 UI 질감과 동일한 수준으로 아트 디렉션한다.

### 구도: 좌/중/우 3영역
- **왼쪽 약 29% · 소속 명단:** 소속 검투사 5~8명 초상 리스트; 소속 전체를 세로 스크롤/페이지 넘김으로 열람; 종류 아이콘·등급·레벨·부상 표시, 선택 캐릭터 강한 금색 장식 테두리. 빈 칸은 시장 영입 버튼.
- **중앙 약 36% · 선택 검투사:** 넓은 석조 원형 단상, 발 고정 5등신에 가까운 실스프라이트, 현재 외형 타입과 성장 단계; 스탠딩/기다리기 애니메이션. 배경에 다른 검투사 실루엣만 절제해서 배치. 장비 표현이 현재 스프라이트에 없다면 가짜 착용 이미지를 만들지 않는다.
- **오른쪽 약 35% · 선수 정보 패널:** 이름, 클래스, 외형 성장 단계 (1~5), Lv., XP 바, 4종 실제 능력치 STR/AGI/END/FOCUS, HP 및 부상 상태, 전적(승/출전), 장착 중 무기/방패/갑옷. UI는 전용 문양과 로마 금박 프레임으로 정돈.
- **하단 메인 액션:** 출전 검투사 지정(가장 강조), 훈련소 이동, 장비실 이동, 치료(비용·잔고 함께 표시), 시장에서 영입. 효과 없는 장식 버튼/장비 슬롯은 금지.
- **비어 있는 상태:** '소속 검투사가 없습니다' + 시장으로 이동, 자동으로 가짜 선수 표시하지 않음.
- **여러 선수:** 누구를 누르든 같은 자리에서 초상/능력/장비/육성 상태가 갱신; 다수 동시 육성·경기별 출전 선수 선택 유지.
- **아트 컨셉:** 로비의 광장과 구별되는 내부 **도미누스 관리실** 또는 로마 루두스 기록관. 배너, 정돈된 명부, 흑단/붉은 가죽/청동 질감. 벽지·배경은 꾸밈이고 UI를 압도하지 않음.
- **용어 규칙:** 도미나는 인물, 독토레는 교관; 관리실 내 선택된 선수만 스탠딩. 선수 성장 이미지는 현재 리소스/스케일 기준을 이용.

### 텍스트 와이어프레임
```
[검투사 관리                              실제 금화 · 명예] 
+---------------------+------------------------+------------------------+
| 소속 검투사  n명    |                        | 검투사 이름 / 레벨    |
| [초상] Lv/등급      |   중앙 선택 선수       | 성장 단계, 경험치     |

| [초상] Lv/등급      |                        | 장착 장비 현황        |

```

## 4. 훈련소

- 승인된 키비주얼을 유지하면서 독토레/훈련 선수는 레이어 분리.
- 훈련 항목별 5개의 버튼(공격/방어/체력/민첩/기술)은 실제 `train(stat)`로 이어짐.
- 사용 중인 선수의 레벨, 기술, 부상과 금화 데이터를 반영.
- 클릭 시 선택 → 소요 비용 → 훈련 성공/실패 반응(실제로 지원되는 메커닉에 맞게). 샘플 텍스트 잔상 제거.
- **좌측 하단 동일 위치** 로비 복귀. 우상단의 장식용 집 그림은 인터랙티브 버튼처럼 보이지 않게 아트 리터칭.

## 5. 장비실

- 승인된 키비주얼과 중앙 석단을 보존하며 실제 선택 선수만 보여줌.
- 무기/방패/갑옷/장신구 탭, 착용 상태, 소유 여부, 구매 비용, 스탯 변동 표시는 실데이터 기반.
- 장착/해제/정렬만 실제 동작하는 버튼으로, 선택 시 강조 프레임·NPC 짧은 반응.
- 지원하지 않는 추가 슬롯, '+', 잠금 아이콘은 버튼처럼 나타내지 않음.
- **좌측 하단 동일 위치** 로비 복귀.

## 6. 검투사시장

- 승인된 시장 상인, 세 후보, 현지 분위기 보존.
- 후보 선택 → 강조 → 고용 확인/취소 → 상인 대사/애니메이션 → 실제 소속 추가 → 빈 단상 → 갱신.
- 루두스로 이동을 누르면 관리실이 아니라 메인 로비로 먼저 복귀; 소속 확인은 로비에서 '검투사 관리' 진입.
- **좌측 하단 동일 위치** 로비 복귀.

## 7. 아레나 출전·전투 결과

- 출전 전 소속 선수 명부, 선택 선수의 초상/능력/부상, 상대의 레벨/등급, 참가/취소를 하나의 전용 출전 선택 화면으로 표시.
- 실제 출전 가능 여부(부상 80 이상 등), 결과 경험치와 전적 저장, 보스 영입 흐름 유지.
- 경기를 끝내고 루두스로 돌아올 때 메인 로비 우선; 전투 종료/재경기는 별도 실제 액션으로 처리.

## 8. 구현 및 QA 순서

1. **긴급 롤백:** 실패한 전체 배경 가림 CSS·JS를 페이지에서 제외하고 도미나 로비 정상 표시.
2. **내비게이션 정비:** 각 서브페이지 복귀 버튼 좌측 하단 1개로 통일; 브라우저 뒤로/화면 전환 중복 리스너 방지.
3. **검투사 관리 재구성(별도 승인 필요):** 3영역 시각 설계안을 먼저 확인받고, 현재 보유 스프라이트와 CAREER 상태에 연결.
4. **아트 패키지:** 오브젝트가 찍힌 바탕 이미지를 원본 파일에서 적절히 복구/분리. 승인된 배경의 큰 영역 위에 불투명 가림판을 얹는 방식으로 대체하지 않음.
5. **페이지별 UI 이관:** 시장, 훈련소, 장비실의 플레이스홀더 숫자와 가짜 버튼을 실데이터/진짜 UI로 단계적 교체.
6. **자동 검사/실기기 검수:** 모든 페이지 링크, 새로고침 저장, 0명/1명/다수 roster, 구매·환불 없음, 훈련 돈 부족, 장비 탈착, 출전/결과/복귀, 좁은 모바일 가로/세로. 최종 스크린샷은 승인 아트와 픽셀 단위로 대조.

## 이번 커밋에서 끝낸 범위와 다음 단계 구분

- 로비 가림판 문제 원인인 별도 polish JS/CSS **HTML 포함을 제거**했고 Cloudflare 복구 배포 확인.
- 관리 화면의 '루두스 로비' 버튼을 **좌측 하단**에 둠; 승인 훈련/장비실의 중복 우상단 클릭 영역을 제거. 시장의 좌측 하단은 기존 동작 유지.
- **아직 미구현:** 관리 전용 3영역 신규 화면, 모든 페이지 합성 키비주얼의 원본 픽셀 클리닝 및 완전한 NPC 애니메이션 추출, 통합 로비 메뉴 전면 기능화. 임의로 완료했다고 표시하지 않는다.
