# Concordia v65 — 대치형 썸네일 조작 / 전략 전술 버튼

2026-10-25

## 대상
전투 상단에 검투사별 버튼 10개와 하단에 별도 엄호/집중/총공세 명령이 있던 **5vs5 협동전** UI. 별개의 실전훈련(무한 웨이브) 화면은 유지.

## UI/UX
- 각 팀 5인 썸네일을 전투 캔버스 **바로 아래**로 이동해 시야 가림 최소화.
- 아군은 오른쪽을 보고, 사람형 적은 왼쪽을 보도록 프레임 자체를 반전. 문구·체력바는 반전하지 않음.
- 상대 출전 대진창 `ludus-cards.js`의 사람형 상대 1~5인도 왼쪽 방향으로 반전. 야수는 기존 방향 유지. 독립형 `ludusOpponentArt` 대기창도 좌우반전.
- 아군 썸네일 터치 => 즉시 `cover` 엄호 7초 발동 (쿨다운 15초).
- 적 썸네일 터치 => 즉시 `focus` 집중공격 6초 발동 (쿨다운 10초).
- 지정한 아군은 **파란색**, 적군은 **빨간색**으로 2.8초 임시 강조. 명령이 실제 활성화된 경우 해당 지속시간 내내 강조. 전장 발좌표에 링/모서리/라벨, 하단 썸네일에도 테두리/상태문구.
- 미발동 때도 쿨다운 및 일시정지 이유를 실시간 메시지와 썸네일에 표시.
- 하단의 별도 엄호 버튼 제거. 전체전술로 교체:
  - **방어진형**: 아군 전원 5.3초간 받는 피해 26% 감소 및 패링 확률 ×1.38, 쿨다운 19초.
  - **양익 돌파**: 아군 전원 4.5초간 이동/돌진속도 1.38배, 발동 시 모든 생존 아군 돌진, 쿨다운 17초.
  - **연계 총공세**: 기존 협공 명령 유지, 연계 게이지 60 필요.
- 기존 시체 불투명/비충돌 및 발 Y기준 깊이 정렬, 5vs5 카메라 확대·복귀는 유지.
