## Fun QA 판단 범위

이번 개선은 입력 반응성과 판정 납득 가능성에 집중했다. 사람 플레이어의 장기 재미 평가나 실제 Android 동시 터치 검증을 완료했다는 의미는 아니다. 자동 전투 승률·경제 성장 곡선을 측정하지 않았으므로 피해량, 보상, 훈련 가격을 임의로 재조정하지 않았다. 다음 관찰 우선순위는 수동 3타→돌진 성공률, 병과별 같은 육성 수준 승률, 야수전 중도 실패의 보상 체감이다.
