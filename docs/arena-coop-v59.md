# Concordia v59 — 전술 협동전 개선 (2026-10-25)

## 현재 구현
- 기존 일반 전투의 5vs5 협동전 모드를 유지하며, 1v1/연속전/실전훈련 로직은 수정하지 않음.
- 10명 모두 동시에 자율 전투. 패링에 성공한 검투사는 스스로 돌진 반격하고 주변 최대 2명이 순차적인 협공을 시도함.
- 강타 넉백을 받은 적에게 최대 3명의 아군이 추격. 그물 포획/틈새 타격도 연계 행동으로 연결됨. 협공은 다시 무한 협공을 생성하지 않음.
- 대시, 견제(짧은 거리 탐색), 간헐적 후퇴와 전선 복귀. 도주 중 충분히 멀리 있고 피격되지 않은 경우에만 소량 체력 회복 가능(도주당 최대 체력의 11%).
- 발 위치 기준 타원형 충돌 영역. 생존 검투사와 쓰러진 시체를 모두 통과할 수 없음. 고속 돌진 및 넉백에도 이동 경로의 충돌을 검사함.
- 시체는 불투명하게 유지되며 제자리에 남음. 충돌 폭과 이동 우회를 함께 조정하여 시체가 전장을 완전히 막는 현상을 완화.
- 이동/반격 잔상 및 견제·도주·회복 상태 표시, 충돌/반격 시각·사운드 피드백 강화.
- 기존 단일 경기 120초 제한, 지휘 명령, 체력 기준 시간 판정, 1회 결과 정산과 저장 방식 유지.

## 검증
- 원래 `tests/arena-coop-core.js` 테스트와 확장된 전술·시체충돌 회귀 테스트를 통과.
- 시드 100개 × 경기 종료까지 재생 결과: 평균 85.1초, 전멸 종료 58회, 시간 판정 42회, 아군 승리 47회. 발 위치 충돌 0건.
- 패링, 돌진, 반격, 포획, 넉백, 협공, 견제, 후퇴, 체력 회복, 전선 복귀 이벤트 생성 확인.
- 수치는 균등 능력치 팀에 대한 결정적 시뮬레이션 결과이며 사용자 플레이테스트 균형 수치는 아님.
- 이번 작업 환경에서는 Playwright 기반 실제 데스크톱/모바일 브라우저 실행을 완료하지 못함. 화면 렌더링과 배포 CDN 반영 여부는 별도 검증 대상.
