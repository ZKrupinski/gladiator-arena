# GLADIATOR ARENA · 야수 애니메이션 제작 표준 (SPRITE FORGE v1)

**목표:** 검증되지 않은 합본 시트/임의 동작 혼용/중복 실루엣/프레임 잘림을 막고, 뉴 챔피언 무르밀로 제작 체계를 야수에게 적용한다.

## 고정 제작 규칙
- 승인된 캐릭터 원화 디자인을 그대로 유지한다. 외형·색·장비 교체 금지.
- 한 번에 캐릭터 하나, **동작 하나**, 총 **8개 서로 다른 완성 자세**만 만든다.
- 4×2 시트 또는 8개 독립 투명 PNG만 입력한다. 통합 보드는 소스에 사용할 수 없다.
- 동작 폭이 크면 원본의 가로/세로 캔버스 자체를 넓힌다. 셀마다 전신·꼬리·무기 등 12px 이상의 투명 안전 여백을 둔다.
- 일괄 경계 검출 뒤 **사람이 실제 애니메이션을 재생하며 승인해야** 게임 사용 가능.
- 출력 960×720의 고정 발 접지 앵커, 프레임마다 위치·크기 변화를 자동 정규화하지 않는다.
- 원본이 잘린 경우 복구된 척하지 않는다. 해당 원본 동작을 다시 그려야 한다.
- 소스가 멀쩡하지 않으면 이전 완성 리소스 대체 금지. 출처별/동작별로 QA 결과를 보존한다.

## 늑대 현재 상태 (2026-10-20)
검수에 사용된 이미지: 이 대화에서 사용자 승인 후 제작한 늑대 4×2 PNG들.
- PASS · idle (대기) 8/8: 셀 경계 접촉 없음.
- PASS · walk (이동) 8/8: 셀 경계 접촉 없음.
- NEEDS QA · attack_claw (공격 초안) 8/8 프레임에 경계 위험.
- NEEDS QA · special_roar (포효) 6/8 프레임 경계 위험.
- NEEDS QA · hit (피격) 8/8 프레임 경계 위험.
- NEEDS QA · death (죽음) 8/8 프레임 경계 위험.
- NOT PRODUCED · run, attack_bite, attack_leap, stagger 동작별 고해상도 원본.
- **결론: 늑대 전체는 아직 게임 교체/배포 승인 상태가 아님.**

## 도구 링크
`public/sprite-forge.html` (/sprite-forge.html). 순수 브라우저에서 동작별 업로드, 프레임 분리, 픽셀 경계·다중 실루엣 검수, 육안 승인, 프레임 재생, JSON 및 검수 ZIP 생성.
검수 툴은 이미지를 새로 그리는 AI 도구가 아니다. 그림 생성은 별도의 아트 제작 단계다.

## 게임 전환 기준
필수 모든 늑대 동작에 대해 각 8프레임이 완성되고, 원본에서 중복·절단·외곽 침범이 제거되고, QA 및 육안 승인 뒤 게임 런타임에 최종 아틀라스 매니페스트를 적용한다.
이전 낡은 wolf-40.png/individual/... 파일은 안전한 전환이 완료되기 전 삭제하지 않는다.
