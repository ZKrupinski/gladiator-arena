# SPARTACUS v63 — 공통 전투 타격감 복구, 잘린 프레임 확대 오류 수정, 챔피언 사망 재생 고정

2026-10-25 / GitHub main

## 원인과 수정
1. **실전훈련 검투사 크기**: 기존 실전훈련은 `202 / 잘라낸 idle 프레임 높이`를 사용하고, 일반 경기 `GrowthFrames.draw`는 잘리기 전 시트의 `cellWidth/cellHeight`를 사용했습니다. 프레임마다 컷팅 크기가 작은 일부 캐릭터의 비정상적인 확대 원인을 해결했습니다.
   - `LudusBridge.practiceNominal(unit)`가 원본 시트 기준 폭/높이를 제공합니다.
   - `PracticeScaleProfiles.cellPixels(look, cellWidth, cellHeight, 202)`는 일반 경기와 똑같이 `min(202/cellWidth,202/cellHeight) * 작품별 저장 배율`을 계산합니다.
   - 실전훈련과 5vs5 모두 같은 공식을 사용합니다. 이미지 프레임의 불투명 영역을 감지해 크기를 키우는 보정은 없습니다.
   - 원본 시트가 아직 로드되지 않은 경우에는 기존 전체 idle 프레임을 임시 기준으로 사용하다, 불러와지면 기준을 갱신합니다.
   - 게임/툴에서 편집·저장한 크기, 발높이, 동작별 아트값은 변경하지 않았습니다.
2. **붉은 투구 챔피언 사망**: `ChampionMurmillo.frame('death', tick)`는 8프레임 modulo 8입니다. 실전훈련이 경기 전체 clock으로 계속 조회하던 부분을, 캐릭터 사망시간부터 0~7까지 한 번만 증가하고 7에서 고정하게 바꿨습니다. 사체 운반에서도 프레임 7을 유지합니다.
3. **전투 연출 복구**:
   - 새 `ArenaCombatFeel` 모듈은 기존 `ArenaMotion`(몸 반동, 순간 크기, 카메라 진동)과 `ArenaFocus`(짧은 정지, 슬로우, 확대, 플래시)를 재사용합니다.
   - 일반 1vs1 경기에서는 `ArenaMotion.visual().scale`을 발 피벗 기준으로 적용합니다 (일시적 반동 최대 11.5%, 캐릭터별 영구 크기 변경 없음).
   - 실전훈련에는 네 번째 공격의 강공격 대시/이펙트, 패링 성공 후 즉시 반격·넉백, 모션 반동·플래시·카메라 진동·짧은 슬로우를 적용했습니다. 1~4인 레이어와 사형집행인 운반 연출은 유지됩니다.
   - 5vs5에는 패링 175px, 밀치기 165px, 기습 154px, 구출 120px 등 더 큰 목표 넉백, 타격 대형 래스터 VFX, 반동 잔상, 공통 화면 연출을 추가했습니다. 실제 이동은 살아 있는 검투사끼리 충돌검사하면서 진행하므로 좁은 공간에서는 멀리 밀리지 않을 수 있습니다.
   - 시체는 계속 불투명, 비충돌, 발 Y기준 정렬 유지합니다.
